# Выбранное направление: «Ночь»

Принято 21 октября 2026 года после двух раундов сравнения.

- Главное событие занимает крупную карточку слева. Обратный отсчёт заметен издалека.
- Остальные события — спокойная смешанная лента справа. На узких экранах она идёт ниже главной карточки.
- Минимум текста: название, владелец, время; место встречи, если оно полезно.
- Нет поясняющих заголовков секций, названий календарей, дублирования профилей и повседневных кнопок «Готово» / «Позже».
- Палитра: фон `#171a21`, главная карточка `#293141`, основной текст `#e9ebf0`, таймер `#dce4f4`, близкий срок `#d4b393`.
- Системный sans-serif, крупные лёгкие цифры. Имя владельца всегда видно текстом, не только цветом.
- Пустое состояние — спокойный экран. Проблемы соединения должны быть видимы отдельно от событий.

Действующий источник дизайна — компоненты и CSS в `apps/web/`. Экспериментальные варианты и скриншоты удалены. Экран использует сохранённые демонстрационные события, живые часы и обратный отсчёт. Приоритет определяет большую карточку; истёкшие карточки исчезают. Пустое состояние реализовано. Добавлены предупреждения о недоступности сервера, хранилища и worker. Интерфейс по умолчанию на английском, русский выбирается в Settings; контент допускает любые Unicode-символы. В карточках сегодня показывается только время, завтра — «Tomorrow»/«Завтра», в ближайшие дни — день недели. Сценарии настраиваются на отдельной странице, а не на основном экране.

Настройки разделены на Scenarios, Connections, Profiles и General (в этом порядке; по умолчанию открываются сценарии). Сценарии отображаются компактными карточками с названием, источником, статусом и следующим запуском. Одна кнопка «Создать сценарий» открывает выбор доступных типов в popup. В «Подключениях» собраны экземпляры интеграций (пока iCalendar), с выбором интеграции при добавлении и кнопкой проверки каждого подключения. Редактирование сценария или подключения открывается на отдельной странице.

Профили людей задают имя и цвет. В формах подключения и сценария владелец выбирается из общего списка. «Общее» — системный профиль. Карточки событий показывают владельца сценария.


## Компоненты UI

- Базовые элементы находятся в `apps/web/components/ui/` (shadcn, Radix). Кнопки-действия — `Button`, ссылки-кнопки — `Button asChild` + `Link`. Цвета кнопок определяет `variant`.
- Карточки — `Card` с вариантами `settings`, `screen`, `preview`, `choice`; заголовки, описания, содержимое и подвал используют соответствующие части Card. `asChild` сохраняет семантику ссылок и заголовков.
- Разделы настроек — `NavigationMenu` с вариантом ссылки `tab`. Это навигация по URL, поэтому ссылки остаются доступными для открытия в новой вкладке.
- Формы — `FieldGroup`, `Field`, `Input`, `Select`, `Checkbox`, `RadioGroup`, `ToggleGroup`. `SettingsField` связывает подпись и описание с контролом. Предупреждения — `Alert`, пустые состояния — `Empty`, подтверждения — `AlertDialog`.
- Палитра и семантические роли находятся в `@theme static inline` в `app/globals.css`. CSS приложения сохраняет текущую геометрию и специфический дизайн экрана событий. Не нужно превращать таймер или схематичный предпросмотр в универсальный контрол.
- Глобальные сбросы элементов должны находиться в `@layer base`. Правило `a { color: inherit }` вне слоя перебивало `text-primary-foreground` у кнопок-ссылок: белый текст на светлом фоне. Не исправлять такие конфликты локальным `!important` или цветом конкретной кнопки.
- При изменениях проверять кнопку и кнопку-ссылку, состояния hover/focus/disabled, диалоги, ширины 1280 и 390 px. Каталог показывает эти состояния и вычисляет контраст цветовых пар.

### Известное ограничение палитры

Исходный красный `#dc4949` даёт около 4.22:1 на фоне `#171a21`, а белый на этом красном — 4.12:1. Это ниже 4.5:1 для обычного текста. Каталог отмечает эти пары; оттенки сохранены в рамках требования не менять дизайн. Основная кнопка после исправления CSS имеет контраст около 9.99:1.

Статусы используют общие варианты `Badge`: `success` — включён / подключён (мягкий зелёный), `inactive` — выключен / ожидание (нейтральная обводка без заливки), `error` — ошибка (мягкий красный), `warning` — устаревшие данные (тёплый оттенок). Выключенное состояние не считается ошибкой.
